Domain Adaptation of Federated Learning by Data Generation and Server Feedback

A federated learning system where the server re-runs each client's model against a shared global test set, explains why it fails on the misclassified samples (SHAP for tabular, Grad-CAM for text), and sends that explanation back. Each client turns the explanation into a generation prompt — TVAE for tabular rows, Gemma 2B for news headlines — to synthesize the specific data it's missing, then retrains locally.

Two independent pipelines share the same feedback→generate→retrain loop, applied to two data types.

The feedback loop

Triggered only when training stalls — plateaued accuracy (tabular) or an overfit / plateau signal (text) — not every round.

1
Clients train locallyEach client fits its model on private data and sends weights back — raw data never leaves the client.
2
Server aggregates & evaluatesFedAvg combines the weights; the server scores the result on its own held-out test set.
↓ if accuracy plateaus / overfits
3
Server diagnoses each clientRuns that client's model on the test set, finds what it gets wrong, and explains why with SHAP (top-k features) or Grad-CAM (salient tokens + position).
4
Client regenerates dataThe explanation becomes a generation target: TVAE samples filtered by cosine similarity, or a Gemma 2B prompt built from salient tokens.
↓
5
Retrain & repeatNew synthetic samples are merged into the client's local training set for the next round.

Note: for the tabular pipeline, the SHAP feedback also includes a few real (but feature-masked) samples from the server's own test set — used only to fill in the synthetic data's missing values, not client-to-client raw data sharing.

Two pipelines

Independent codebases in /tabular and /text, each with its own server, client, dataset and README.

Tabular SHAP → TVAE

5clients, 70/30 split
Binarychurn (Exited)

Bank customer churn classification with a 5-layer MLP. When accuracy plateaus, the server runs SHAP on each client's misclassified test samples and returns the top-10 most important (partially masked) features. The client fills the gaps with a restore-TVAE, then samples a pre-trained generator TVAE and keeps only synthetic rows whose cosine similarity to the feedback exceeds 0.9.

  • server_tabular.py · client_tabular.py
  • Dataset: Kaggle Bank Customer Churn (scaled features)
  • Plateau window 3 rounds, Δaccuracy < 0.01

Text Grad-CAM → Gemma 2B

5clients
42news categories

News headline classification with fine-tuned DistilBERT. On overfit or plateau, the server runs Grad-CAM on each client's misclassified test headlines, keeps the 3–10 most salient tokens with their position (beginning/middle/end), and sends that per-class. The client prompts Gemma 2B to write a new headline containing those tokens in those positions, validates length and token coverage, then adds it to its training set.

  • server_textdata.py · client_textdata.py
  • Dataset: HuffPost News Category (42 classes)
  • Checkpointed & resumable rounds; runs clients on Colab

Features

  • Failure-driven feedback: only misclassified samples on the server's test set are explained
  • SHAP top-k features (tabular) / Grad-CAM salient tokens + position (text)
  • Generative augmentation targeted at the diagnosed weak points, not random data
  • Cosine-similarity filtering keeps only synthetic rows that match the feedback (tabular)
  • Plateau / overfit detection triggers feedback only when training actually stalls
  • Server-side round timing and accuracy/precision/recall/F1 logged to CSV every run

Quick start

Each pipeline is self-contained — clone once, then run either independently.

Tabular

git clone https://github.com/CaoDien2003/flLgenai.git
cd flLgenai/tabular
pip install -r requirements.txt

python server_tabular.py
python client_tabular.py --client-id client1 \
  --train-csv dataset/7030/train1.csv \
  --server-address 127.0.0.1:9000 \
  --log-dir logs/exp01

Run once per client with a unique --client-id — the server keys its feedback by this id.

Text

git clone https://github.com/CaoDien2003/flLgenai.git
cd flLgenai/text
pip install -r requirements.txt

python server_textdata.py --num_rounds 30 --ckpt_every 5
python client_textdata.py   # one per client

Requires a Hugging Face login token with access to google/gemma-2b-it.
